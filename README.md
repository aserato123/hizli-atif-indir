# Hızlı Atıf — İndir

**[Windows için Hızlı Atıf'ı indir](https://github.com/aserato123/hizli-atif-indir/releases/latest/download/Hizli-Atif-Kurulum.exe)**

Kurulum dosyasını çalıştırın. Kurulumdan sonra **Ctrl + Shift + Boşluk** ile atıf panelini açın.

Bu depo yalnızca kurulum dosyasını dağıtmak içindir. Hızlı Atıf kapalı kaynaklıdır; kaynak kod bu depoda paylaşılmaz.
